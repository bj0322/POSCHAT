# POSCHAT 1.17.0 — Adaptive Hybrid AI Engine (로컬 AI·자동 모델 선택·3단계 Cloud)

> 개발 중인 버전입니다. 릴리스(태그·배포)는 사용자 승인 뒤에만 합니다.

## AI 실행 정책: 요청마다 알맞은 모델을 자동으로 (새 기능, 기본 꺼짐)
**설정 → AI 실행 정책 → 열기**에서 켭니다. 요청의 종류·난이도·개인정보·이 PC의 로컬 모델·비용을 보고 **로컬 AI(Ollama)**, **경량 Cloud 모델**,
**프런티어 모델** 중 하나를 고릅니다. 켜기 전에는 예전과 똑같습니다. 자세히: [설정](../adaptive-ai-setup.md) · [구조](../architecture/adaptive-ai.md) ·
[보안](../adaptive-ai-security.md) · [평가](../adaptive-ai-evaluation.md) · [벤치마크 결과](../adaptive-ai-benchmark-results.md)

- **정책 4가지**: Economy(가벼운 일은 로컬), **Balanced**(권장, 연구·코드·에이전트는 Cloud 먼저), Quality(Cloud 먼저, 측정된 일만 로컬),
  **Local Only**(Cloud 모델을 전혀 부르지 않음 — PO노트 노트·대화 요약·음성 보정까지 막고, 로컬이 못 하면 오류로 알림).
- **대화 모델**: 목록에 **자동 (AI 실행 정책)**과 **로컬 · 모델 이름**이 생깁니다. 자동만 정책대로 고르고, 직접 고른 모델은 바꾸지 않습니다.
  자동 선택을 켜면 새 대화는 '자동'으로 시작합니다. Cloud 키가 없어도 로컬 모델로 대화할 수 있습니다.
- **왜 이 모델인지**: 답변 아래 `Local · 요약`, `Cloud · 연구 추론`, `Light ⇄ Frontier · 연구 추론`, `Local → Cloud · 요약` 같은 표시를 누르면
  고른 모델·이유·작업·정책·응답 시간·Cloud 호출 여부·비용 추정·검증 결과·승격·상담이 보입니다.

## 로컬 AI (Ollama)
- 이 PC의 Ollama(`http://127.0.0.1:11434`)에 연결합니다. 앱은 Ollama나 모델을 함께 설치하지 않습니다(설치는 [ollama.com](https://ollama.com/download)).
- 정책 창에서 연결 시험, 설치된 모델의 크기·양자화·메모리 추정·문맥·기능(이미지·도구·JSON)·라이선스, 속도 측정, 시험 대화, 지우기.
- **모델 받기**: 받기 전에 Ollama 공개 저장소에서 크기·출처·라이선스와 남은 디스크를 보여 주고, 누를 때만 받습니다(진행률·멈춤).
- 다른 PC의 Ollama는 '원격 허용'을 켰을 때만(사설망 http, 인터넷은 https만). 클라우드 메타데이터·링크 로컬 주소는 언제나 막고, 리다이렉트를 따라가지 않으며, API 키를 보내지 않습니다.
- 안드로이드에서는 쓸 수 없습니다(자동 선택은 Cloud 모델 사이에서만).

## 3단계: 사용자 → 경량 모델 → 프런티어 (새 기능, 선택)
**경량 Cloud 모델**(Claude Haiku 5.5·GPT-5 mini·Gemini Flash 등)을 고르면, 보통 일은 경량 모델이 답하고 어려운 일은 경량 모델이 대화를 이끌며
확신이 없는 부분만 **프런티어 모델에 짧게 상담**합니다. 프런티어는 대화 전체 대신 질문과 발췌만 받고, 상담 기록은 대화마다 남아 다음 상담에 이어집니다.
파일·명령·외부 작업으로 이어지는 에이전트 단계는 언제나 프런티어가 맡습니다. 상담하면 경량 모델을 한 번 더 부르므로 조금 느립니다.

## 품질 검증과 승격
- 로컬·경량 모델의 답을 규칙으로 검증합니다: 빈 답·끊김·반복·언어·JSON·단계 형식, 웹페이지·논문의 주소·인용·쪽 번호·수치, Lab 수치의 근거, 코드 문법.
  모델이 스스로 말한 '확신'은 보지 않습니다.
- 통과하지 못하면 허용한 경우에만 위 단계(로컬 → 경량 → 프런티어)로 다시 답합니다. 받는 동안은 '검증 전'으로 보이고, 다시 답하면 먼저 받은 답을 접어서 함께 보여 줍니다(조용히 덮지 않음).
- 다시 하기·승격은 모델 호출 안에서 끝나므로 에이전트의 파일 수정·명령·외부 쓰기가 두 번 일어나지 않습니다. 승인 창은 그대로입니다.

## 비용·통계
- 주간 Cloud 호출·크레딧 한도, 요청당 크레딧 한도. 크레딧은 앱 안내에 근거가 있는 모델만 추정하고, POSTECH 크레딧과 Claude API 요금(USD)은 바꾸거나 더하지 않습니다.
- **연결·도구 → 사용량·진단 → Adaptive AI**: 로컬로 끝낸 비율, Cloud가 답한 비율, 경량 모델·상담, 승격 비율, 평균·p95 지연, 검증 통과율, 👍👎, 요청당 크레딧,
  로컬로 처리해 쓰지 않은 Cloud 크레딧(추정), 프런티어 입력 토큰 줄임(추정). 로컬의 비용 0은 Cloud API 비용만 0이라는 뜻입니다.
- 기록에는 질문·답·첨부·상담 내용이 없습니다(작업 유형·모델·시간·토큰 추정·검증 결과만).

## 기능별
- 채팅·에이전트(단계마다 목적에 따라), 브라우저·논문·코드·Lab에서 '채팅에 첨부해 묻기'(첨부 종류로 작업과 검증 영역을 알아봄),
  Code 에이전트(코드 수정 단계는 프런티어 먼저, Local Only면 로컬), PO노트 노트 만들기(받아 적기는 PO노트 설정 그대로), 대화 요약.

## 벤치마크
- `tools/data/adaptive_benchmark.json` 224개(일반·브라우저·논문/연구·코드·Lab·에이전트, 한국어, 정답·검증 방법·라우팅 정답)와
  `tools/adaptive_benchmark.py`(A Cloud만 ~ G 3단계+상담, 오프라인 라우팅 평가, Cloud 호출 상한).
- 오프라인 라우팅(Balanced, 시험용 절반): 로컬 48.2%, 라우팅 정확도 91.1%. **실제 품질·비용 비교는 아직 하지 않았습니다**(사용자 PC에서 측정 필요).
- 사용자 PC 점검: `python tools/local_ai_check.py --model <모델>`.

## 알려진 한계
- 로컬 모델·경량 모델의 실제 답 품질과 비용 절감은 측정 전입니다. 목표(비용 30% 절감·성공률 하락 2%p 이내) 달성 여부를 아직 모릅니다.
- 규칙 검증은 일부만 확인합니다(통과가 정답을 뜻하지 않음). 연구 추론의 내용 품질은 사람이 평가해야 합니다.
- 라우터는 한국어·연구 작업에 맞춘 규칙과 간단한 의미 분류입니다. '무엇이 더 필요한지 분석해 줘'처럼 질문 꼴의 분석 요청을 쉬운 일로 잘못 볼 수 있습니다.
- 실제 Windows·macOS 앱에서 Ollama를 연결해 손으로 확인하는 일이 남았습니다.
