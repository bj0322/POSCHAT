# POSCHAT 1.18.8 — PLMS 베타 표시와 토큰·검색 효율

## 바뀐 점

- **PLMS는 베타 기능**: 사이드바 기능 버튼 맨 아래로 옮기고 눈에 띄는 **베타** 배지를 달았다. PLMS 창 제목·안내, 사용법 가이드, 설정의 PLMS 계정에도 베타로 적었다.
- **토큰 효율**: 에이전트 진행 기록에서 같은 읽기·목록 결과를 한 줄로 줄이고, 이전 대화·첨부·스킬 목록·memory.md·USER.md·AGENTS.md·CLAUDE.md는 길이를 제한해 프롬프트를 줄였다. 읽은 문서 캐시에 글자 수 상한을 두었다.
- **프롬프트 캐싱 기본 켜짐**: 여러 단계를 도는 에이전트 작업과 상담에서만 쓰고, 한 번에 끝나는 대화에는 쓰지 않는다. 설정 → AI 실행 정책에서 끌 수 있다.
- **대화 검색 색인**: 다른 대화를 찾을 때 대화 파일을 전부 다시 읽지 않고, 바뀐 대화만 색인(`thread_index.db`)에 반영한다. 결과는 예전과 같다. 색인은 지워도 다시 만들어진다. 처음 한 번은 색인을 만드느라 조금 더 걸린다.
- **자동 업데이트를 GitHub 릴리스에서**: 저장소가 공개라서 앱이 `pidstech/POSCHAT`의 GitHub 릴리스에서 새 버전을 확인하고 받는다. GitHub에서 받지 못하면(요청 한도·접속 문제) 기존 업데이트 서버로 한 번 더 시도한다. 설치 파일은 어느 쪽에서 받든 서명·크기·SHA-256을 확인한 뒤에만 설치한다. 1.18.7 이하 앱은 계속 업데이트 서버를 본다.
- **내부 정리**: 공용 `ToolFailure`·HTTP 도우미를 `net.py`로 분리했다. graphify 출력에서 제3자 라이브러리를 빼고 다시 만들 수 있는 파일은 저장소에서 뺐다.

## 한계

- PLMS는 실제 학교 계정·Windows·macOS 앱에서 손으로 확인하지 못했다(베타).
- 프롬프트가 짧아지는 대신 길게 쌓인 이전 대화·메모리는 일부만 모델에 들어간다. 필요하면 `recall` 단계나 대화 검색으로 찾는다.
- 캐싱·길이 제한의 실제 토큰 절감폭은 개발자 모드(설정)의 실측 값으로 확인해야 한다.
