# POSCHAT 1.14.0 — 논문 읽기(POSCHAT Paper)

## 논문 읽기 (새 기능)
- 왼쪽 사이드바의 **논문**을 누르면 채팅 오른쪽에 논문 화면이 열립니다. 가운데 막대를 끌어 너비를 바꿉니다(다음에 열 때도 그 너비). 휴대폰에서는 논문 화면이 채팅을 덮고, 질문을 첨부하면 채팅으로 돌아갑니다.
- 여는 방법: **PDF 파일 열기**(이 기기의 PDF, 60MB까지), **arXiv 번호**(예: `1706.03762`)나 PDF 주소, **최근에 연 논문**, **연구 라이브러리**의 논문(PDF가 연결됐거나 arXiv 번호가 있는 것 — arXiv PDF는 처음 열 때 한 번 받아 라이브러리에 연결합니다).
- 쪽 이동·확대·축소·너비 맞춤. 글자를 드래그해 고를 수 있습니다(한글 논문의 CJK 글꼴 포함).
- **선택한 부분 묻기**: 드래그한 문장을 쪽 번호와 같은 쪽 전체(맥락)와 함께 첨부합니다.
- **이 쪽 묻기**: 보고 있는 쪽의 글을 첨부합니다.
- **영역 잘라 묻기**: 그림·표·수식을 드래그하면 화면보다 선명하게 다시 그려 이미지로 첨부합니다(이미지를 읽을 수 있는 모델에서 씁니다).
- **논문 요약**: 첫 쪽(제목·초록)과 실험·결과 낱말이 많은 쪽을 발췌해 첨부하고, 연구 질문·방법·실험 조건·결과·한계를 쪽 번호와 함께 요약해 달라고 요청합니다.
- **비교표**: 첫 화면의 연구 라이브러리 목록에서 2~6편을 고르고 **선택한 논문 비교**를 누르면, 논문마다 실험·결과 쪽 발췌(PDF가 없으면 초록)를 첨부하고 실험 조건·결과(수치)를 표로 비교해 달라는 질문을 넣습니다. 칸마다 근거 쪽을 (논문 p. N)으로 답니다.
- **라이브러리에 저장**: 연 PDF를 연구 라이브러리에 더합니다. PDF에서 DOI·arXiv 번호를 찾으면 논문 정보를 채웁니다(연구 라이브러리를 켜 두어야 합니다).
- **에이전트**: 에이전트 모드에서 `paper_read`로 열린 논문(또는 연구 라이브러리 논문의 PDF)을 필요한 쪽만 읽습니다. 쪽을 주거나, 낱말을 주면 그 낱말이 많이 나오는 쪽을 읽고, 답에 (p. N)으로 근거를 밝힙니다.

## 구현과 안전
- PDF는 PDF.js 6.4(Apache-2.0, `web/vendor/pdfjs`)로 그립니다. 앱 안에 함께 들어 있어 인터넷 없이 열립니다. PDF 해석은 웹 워커에서 하고(앱 API가 없는 곳), 화면 쪽은 코드 생성(`eval`)을 끄고, PDF 안의 스크립트·양식·링크는 그리거나 실행하지 않습니다(그림과 투명 글자 층만).
- 질문·요약·비교에 쓰는 글자는 pypdf로 쪽마다 뽑아 `[p. N]` 표시를 붙이고, '외부 데이터'로 감싸 넘깁니다. 논문 안에 "이전 지시를 무시하고…" 같은 문장이 있어도 따르지 않습니다.
- 화면이 열 수 있는 파일은 화면에서 고른 파일, 최근 목록, 라이브러리 논문뿐입니다. 받은 PDF와 고른 PDF는 데이터 폴더의 `research/pdfs`에 둡니다.
- 시험: 쪽 글자·쪽 고르기·발췌, 화면 API(열기·조각 전송·첨부·그림·비교·저장), 에이전트 `paper_read`, 그리고 Chromium에서 실제로 PDF를 그리고 선택·쪽·영역을 첨부하는 화면 시험.

## 1.13.0 이후 바뀐 점
- 브라우저와 논문 화면은 오른쪽 자리를 함께 쓰므로 하나를 열면 다른 하나는 닫힙니다.
- 에이전트의 '외부 데이터' 규칙은 이제 항상 프롬프트에 들어갑니다(논문·첨부도 외부 데이터이므로).
