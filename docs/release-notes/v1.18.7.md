# POSCHAT 1.18.7 — PLMS 자료 보기와 확인 범위

## 바뀐 점

- **PLMS 수업 목록**: 같은 수업 ID가 반복되면 한 번만 표시한다.
- **강의자료 보기**: PDF는 앱에서 쪽별로 미리 본다. PPT·PPTX는 설치된 PowerPoint 호환 앱에서 원본을 열거나 내려받는다.
- **AI 확인 범위**: 수업 전체 정리 시 목록과 자료를 이어 읽도록 안내하고, 답변에 실제로 연 수업·자료 수와 수업 목록에서 아직 열지 않은 항목 수를 표시한다. 목록이나 본문이 앱의 제한을 넘으면 알린다.
- **사이드바**: 브라우저·코드·논문·PO노트·도구 화면을 열면 접혀 작업 공간이 넓어진다. 화면의 사이드바 버튼으로 다시 열 수 있다.
- **도구와 스킬**: Context7을 기본 꺼짐 추천 MCP 서버로 추가했다(Node.js와 인터넷 필요). RTK 사용 및 ECC 맥락 요약 스킬을 내장했다. RTK 실행 파일은 별도 설치한다.

## 한계

- 실제 POSTECH 계정에서 중복 수업, 인증과 강의자료 형식은 아직 손으로 확인하지 못했다.
- AI의 단계 한도·읽기 오류·하위 항목·긴 문서 때문에 수업 전체를 읽었다고 보장하지 않는다. 예전 PPT와 스캔 PDF의 텍스트 추출은 지원하지 않는다.
- PowerPoint 보기는 PC에 호환 앱이 필요하다. [PLMS 사용법](../plms-guide.md).
