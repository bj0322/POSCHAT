# POSCHAT 1.11.0

## 이름을 POSCHAT으로 정식 변경
- 창 제목, 사이드바, 시작 메뉴·바탕화면 바로가기, Windows '설치된 앱' 목록, 실행 파일 정보(작업 관리자), macOS 앱 이름, 안드로이드 앱 이름, 릴리스 파일(`POSCHAT-Setup.exe`·`POSCHAT-mac.dmg`·`POSCHAT.apk`)이 모두 POSCHAT입니다.
- 이전 버전 위에 그대로 업데이트되도록 설치 폴더·실행 파일(`PostechChat.exe`, `PostechChat.app`)·데이터 폴더(`%APPDATA%\PostechChat`)·OS 보안 저장소 항목 이름은 바꾸지 않았습니다. 대화·설정·노트는 그대로 남습니다.
- 업데이트하면 예전 이름(POSTECH GenAI Chat)의 바로가기를 지우고 POSCHAT 바로가기를 만듭니다.
- 1.9.1~1.10.0 앱의 자동 업데이트가 계속 되도록 릴리스에 예전 파일 이름(`PostechChat-*`)도 함께 올립니다.

## 일반 AI 모델 (Claude): 본인 Claude API 키로 쓰기
- **설정 → API 방식 → 일반 AI 모델 (Claude)**를 고르고 [Anthropic 콘솔](https://console.anthropic.com)에서 만든 Claude API 키를 넣으면, 대화·에이전트·PO노트 노트 만들기·대화 요약·모델 평가 같은 모든 모델 호출을 그 키로 Claude API에 보냅니다. 기본은 그대로 POSTECH GenAI입니다.
- 모델: Claude Opus 5.5(권장)·Sonnet 5.5·Haiku 5.5·Fable 5.1. '모델 목록 불러오기'로 그 키로 쓸 수 있는 모델을 모두 받아 옵니다. 대화별 모델 선택, 스트리밍, 이미지 첨부를 지원합니다.
- 요금은 그 키의 Anthropic 계정으로 청구되고 POSTECH 크레딧은 쓰지 않습니다.
- 키와 기본 모델은 POSTECH 쪽과 따로 저장하므로 API 방식만 바꿔 오갈 수 있습니다. 키는 이 기기의 config.json에 저장되고 동기화되지 않습니다. 환경 변수 `ANTHROPIC_API_KEY`도 씁니다.
- Claude API는 음성을 받지 않으므로 PO노트의 서버 음성 보정과 크레딧 확인은 POSTECH 키가 있을 때만 씁니다(없으면 로컬 AI로만 받아 적습니다).
- Opus 5.5·Sonnet 5.5·Fable 5.1이 안전 정책으로 답하지 않으면 Anthropic이 권하는 다른 모델이 다시 답합니다(server-side fallback). 그래도 답하지 않으면 그 이유를 알립니다.
- 데스크톱은 공식 Anthropic Python SDK를, 안드로이드는 SDK를 설치할 수 없어(Chaquopy에 pydantic-core·jiter가 없음) 같은 요청을 HTTP로 보냅니다.

## 연구 라이브러리·에이전트 자동화 화면
- '연결·도구' 창의 탭이던 **연구 라이브러리**와 **에이전트 자동화**를 PO노트처럼 왼쪽 사이드바 위쪽에서 바로 여는 본문 화면으로 옮겼습니다.
- 연구 라이브러리: 논문 · 문서 검색 · 벡터 검색 탭, 논문 더하기 카드, 태그 칩, 작업 폴더 인덱싱과 원문 찾기 카드.
- 에이전트 자동화: Python · Jupyter / 원격 서버(SSH) / 실행 기록 탭.
- 꺼져 있을 때는 무엇을 하는 기능인지와 켜기 버튼을 먼저 보여 줍니다. 휴대폰 화면에도 맞습니다.
- '연결·도구' 창에는 커넥터·MCP 서버·메모리·동기화·사용량·진단이 남습니다.

## 고친 버그
- **업데이트할 때 '설치'를 두 번 눌러야 하던 문제**: 앱이 설치 프로그램을 연 뒤 닫히는 데(녹음 저장·내장 MCP 서버 정리) 몇 초 걸리는 동안 '설치'를 누르면 "실행 중"이라며 멈췄습니다. 이제 설치 프로그램이 앱이 닫힐 때까지 기다렸다가 이어서 설치하고, 30초가 지나도 닫히지 않으면 강제로 종료할지 묻습니다. 앱도 업데이트로 창을 닫으면 정리 후 바로 종료하고, 멈춰도 15초 뒤에는 끝납니다. (1.10.0 이하에서 업데이트할 때도 새 설치 프로그램이 기다리므로 바로 적용됩니다.)

## 확인하지 못한 것
- 실제 Anthropic 계정 키로 호출해 보지는 못했습니다(Claude API와 같은 형식의 가짜 서버로 SDK·HTTP 두 경로를 시험).
