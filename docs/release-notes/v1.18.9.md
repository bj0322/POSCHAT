# POSCHAT 1.18.9 — 공개 배포 전 보안 보강

공식 다운로드 링크를 배포하기 전에 전체 코드를 검토하고, 웹페이지·문서·이메일 같은 외부 내용에 심은 지시(프롬프트 인젝션)가
사용자 PC에서 할 수 있는 일을 줄였다.

## 바뀐 점

- **'다시 묻지 않기' 규칙 우회 차단**: Code 에이전트의 규칙(예: `pytest`)이 `pytest & 다른 명령`처럼 단일 `&`로 이어 붙인 명령까지 허용하던 문제를 고쳤다. cmd.exe의 `^`·`%변수%`와 줄 바꿈도 막는다.
- **채팅 화면이 외부 이미지·위험한 링크를 불러오지 않음**: 답변의 `![](https://…)` 이미지는 그리지 않고 대체 글과 주소만 글자로 보여 준다(그리는 순간 대화 내용이 주소에 실려 나갈 수 있었다). 링크는 `https`·`http`·`mailto`만 남기고, `//host/…`(Windows 네트워크 공유)·상대 주소·`file:` 링크는 주소를 지운다. 수식(KaTeX)과 앱이 만든 이미지는 그대로다.
- **텍스트 첨부는 앱 안에서 보기**: `.bat`·`.js`·`.vbs`·`.html` 같은 텍스트로 받은 첨부를 누르면 기본 앱으로 열지(실행하지) 않고 앱 안의 창에 내용을 보여 준다. 이미지·문서(PDF·Office·한글)는 전과 같이 기본 앱으로 연다. 매크로가 들 수 있는 `.xlsm`은 열지 않고 읽은 내용만 보여 준다.
- **채팅 에이전트 명령**: API 키·토큰 같은 비밀 환경 변수를 명령에 넘기지 않고, 출력에 나온 비밀은 가린다(Code·Lab과 같은 기준, ssh-agent 소켓은 넘긴다). 지우기·덮어쓰기·네트워크·`python -c` 같은 명령 줄 코드 실행은 '모두 자동 허용'이어도 매번 묻는다.
- **명령 줄 코드 실행 판정**: `python -c`·`node -e`·`powershell -enc`·`sh -c`·`cmd /c`·`find -delete`·`Remove-Item -Recurse`를 위험한 동작으로 본다. Code의 '전체 자동'과 '다시 묻지 않기'도 이런 명령은 묻는다.
- **API 키를 OS 보안 저장소에**: 설정 창의 API 키·토큰(POSTECH·Claude·OpenAI·Notion·Firecrawl)을 `config.json`(평문, 백업에 복사됨) 대신 Windows 자격 증명 관리자·macOS 키체인의 항목 하나에 둔다. 처음 실행할 때 예전 값이 자동으로 옮겨지고 `config.json`과 이후 백업에서 빠진다. `config.json`은 소유자만 읽을 수 있게 저장한다.
- **업데이트 내려받기 대체 경로**: GitHub 피드는 되지만 파일 서버만 막힌 망에서도, 업데이트 서버에서 피드·서명·파일을 받아 설치한다. 업데이트 서버의 www 주소로의 이동도 받아들인다.
- **외부 주소 열기 제한**: 앱이 브라우저로 여는 주소는 `http(s)`와 있는 로컬 폴더만 받는다. 플러그인 홈페이지 등 데이터에서 온 링크도 `http(s)`만 링크로 만든다.
- **Lab(Windows)**: 파라미터 값을 늘 큰따옴표로 감싸 `a&calc`가 명령 두 개로 갈라지지 않게 했다. `"`·`%`·`!`는 Windows에서 받지 않는다.
- **릴리스 점검**: 릴리스 태그가 `vX.Y.Z`이고 `version.py`와 같을 때만 업데이트 서명·릴리스를 한다. 워크플로 기본 권한을 읽기 전용으로 낮추고 릴리스 작업만 쓰기 권한을 받는다.
- **문서**: 소스 실행·빌드에 필요한 Python을 3.11 이상으로 바로잡았다(`tomllib`).

## 한계

- macOS판은 Apple 개발자 서명이 없어서, 업데이트한 뒤 처음 실행할 때 키체인 접근을 물을 수 있다. **항상 허용**을 누르면 그 버전에서는 다시 묻지 않는다. 거부하면 설정 창에서 키를 다시 넣어야 한다.
- 1.18.8 이하로 되돌리면 비밀 저장소로 옮긴 API 키를 다시 넣어야 한다.
- 같은 사이트에서 한 번 허용한 주소 다음의 물음표(?) 없는 주소는 이번 작업 동안 다시 묻지 않는다(승인 창에 적은 대로).
- 사용자가 추가한 외부 MCP 서버에는 지금처럼 환경 변수 전체를 넘긴다(서버가 키를 환경 변수에서 읽는 경우가 많다).
- Content-Security-Policy는 Windows(WebView2)·macOS(WKWebView)의 file:// 화면에서 확인한 뒤 넣는다.
