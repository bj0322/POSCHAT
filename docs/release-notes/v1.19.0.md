# POSCHAT 1.19.0 — 공개 전 사용자 피드백 반영

공개 배포 전에 받은 사용성 피드백 9가지를 반영했다.

## 바뀐 점

- **시작할 때 창 크기**: 설정 → *시작할 때 창 크기*에서 기본 창·최대화·전체 화면을 고르면 다음에 앱을 열 때부터 그 크기로 연다. 지금 창은 **F11**로 전체 화면을 켜고 끈다.
- **브라우저 버튼 위치**: *기본 브라우저로 열기*와 *닫기*를 채팅 위 주소 표시줄에서 빼서, 오른쪽 웹페이지 바로 위 막대(페이지 제목과 함께)로 옮겼다. 무엇을 닫는지 바로 보인다. 주소 입력·뒤로·앞으로·새로 고침·AI에게 묻기는 그대로 채팅 위에 있다.
- **사이드바 유지**: Lab·연구 라이브러리·에이전트 자동화·플러그인을 열어도 왼쪽 사이드바를 접지 않는다(다른 기능으로 바로 옮겨 갈 수 있다). 브라우저·논문·코드처럼 옆 화면이 넓어야 하는 기능과 휴대폰처럼 좁은 화면은 전과 같다.
- **PLMS 계정 바로 저장**: PLMS 창에서 *계정을 설정에 저장해 두기*를 누르면 아이디·비밀번호를 그 자리에서 저장하고, 다음부터 브라우저를 열지 않고 자동으로 로그인한다. 비밀번호는 전과 같이 OS 보안 저장소에만 둔다.
- **플러그인 설명 한국어**: 플러그인과 스킬·명령 설명 341개를 한국어로 옮겼다. 영문 원문은 *영문 원문*을 눌러 볼 수 있고, 검색은 한국어·영어 모두 된다. 새로 생긴 스킬처럼 번역이 없는 항목은 원문만 보인다.
- **링크 색**: 링크를 화면 테마에 맞춘 색(어두운 화면에서는 하늘색)으로 바꾸고, 한 번 연 링크는 연보라로 구분한다(이 기기에 기억).
- **토큰 사용량 그래프**: 설정·`/usage`·연결·도구 → 사용량·진단에 최근 30일 날짜별 토큰 그래프(입력·출력)를 더했다. 막대에 마우스를 올리면 그날의 호출 수와 토큰이 보인다.
- **사용법 가이드**: 설정 맨 위에 큰 *사용법 가이드* 카드를 두고, 가이드 창에 큰 제목과 목차를 더했다. 목차를 누르면 그 항목이 펼쳐진다.
- **설치 파일 줄이기·설치 시간 단축**: 앱이 쓰지 않던 Pillow AVIF 코덱(7.5MB)과 setuptools를 빼고, 설치할 때 설치 파일 전체를 한 번 더 읽어 확인하던 단계를 없앴다(파일을 풀면서 같은 손상 검사를 한다).

## 한계

- 브라우저 웹페이지 위 막대는 Windows(WebView2)·macOS(WKWebView) 네이티브 컨트롤이다. 막대를 만들지 못하면 예전처럼 채팅 위 주소 표시줄에 두 버튼이 보인다.
- 플러그인 번역은 2026-10-31 기준 Knowledge Work Plugins 목록을 옮긴 것이다. 원문이 바뀌면 번역이 예전 내용일 수 있으니 *영문 원문*을 함께 확인하세요.
- Windows SmartScreen·Chrome의 다운로드 경고는 이번 버전에서 다루지 않았다(코드 서명 인증서가 필요하다. 로드맵의 Future Work).
