# POSCHAT 1.11.1

## 고친 버그
- **업데이트 뒤 앱이 열리지 않던 문제**("Failed to load Python DLL ... python312.dll", 설치 중 "[WinError 5] 액세스가 거부되었습니다: ...\_internal\VCRUNTIME140.dll")
  - 원인: 1.11.0 설치 프로그램은 이전 버전의 `_internal` 폴더를 먼저 지운 뒤 새 파일을 풀었습니다. 다른 프로세스나 백신이 그 안의 DLL을 붙잡고 있으면 지우다 멈춰, 반쯤 지워진 폴더가 남았습니다.
  - 이제는 새 파일을 설치 폴더 안의 임시 폴더에 모두 푼 뒤 이전 파일과 바꿉니다. 이전 파일은 지우지 않고 옆으로 옮겨 둡니다. 쓰는 중인 DLL도 같은 디스크 안에서는 옮길 수 있어서, 폴더째 옮기지 못하면 파일을 하나씩 옮깁니다.
  - 그래도 바꾸지 못하면 이전 파일을 제자리로 되돌리므로, 설치가 실패해도 이전 버전은 그대로 실행됩니다.
  - 옮겨 둔 이전 파일은 지울 수 있을 때 지우고, 못 지우면 다음 설치 때 지웁니다.
  - 1.11.0에서 이 문제로 앱이 열리지 않는다면, Releases의 `POSCHAT-Setup.exe`(1.11.1)를 받아 같은 폴더에 설치하면 고쳐집니다. 대화·설정은 그대로 남아 있습니다.
- CI가 같은 폴더에 한 번 더 설치(업데이트)한 뒤 앱이 실행되는지까지 확인합니다.
