# POSCHAT 1.18.2 — 자체 업데이트 서버, 서명 확인

저장소를 비공개로 바꿔도 자동 업데이트가 계속되도록, 새 버전 확인과 설치 파일 받기를 PIDS Tech. 업데이트 서버로 옮겼습니다. 이 서버 주소는 http라서, 설치 파일은 **서명을 확인한 뒤에만** 설치합니다.

## 바뀐 점
- 앱은 GitHub 대신 업데이트 서버(`updates.UPDATE_BASE_URL`)에서 새 버전을 확인하고 이 기기용 설치 파일(`POSCHAT-Setup.exe`·`POSCHAT-mac.dmg`·`POSCHAT.apk`)을 받습니다. 서버는 GitHub 릴리스를 10분마다 가져옵니다([운영 안내](../update-server.md)).
- 설치 파일마다 릴리스 CI가 Ed25519 서명(`<파일>.sig`)을 만들어 올리고, 앱은 안에 든 공개키로 서명·크기·SHA-256을 확인합니다. 서명이나 digest가 없거나 맞지 않으면 설치하지 않습니다(건너뛰는 설정 없음). 서버 요청은 리디렉션을 따르지 않습니다.
- 서명 도구 `tools/update_sign.py`(키 만들기·서명)와 키 교체 방법([docs/security.md](../security.md#업데이트-신뢰-모델)).
- 개인정보 처리방침: 개발자가 운영하는 서버는 업데이트 서버 하나뿐이며, 앱은 여기에 IP 주소와 일반적인 HTTP 정보 외에 아무것도 보내지 않습니다.

## 1.18.1 이하에서 올리기
1.18.1 이하 앱은 GitHub에서 업데이트를 확인합니다. 그래서 1.18.2는 저장소가 공개인 동안 올리고, 사용자가 1.18.2로 올라간 뒤에 저장소를 비공개로 바꿉니다. 그 전에 비공개로 바꾸면 1.18.1 이하 앱은 자동 업데이트를 받지 못하므로 업데이트 서버 링크에서 설치 파일을 직접 받아야 합니다.

## 알려진 한계
- 업데이트 서버는 아직 http(IP 주소)입니다. 서명으로 변조는 막지만 도청은 막지 못합니다. 도메인과 HTTPS가 생기면 `UPDATE_BASE_URL`만 바꿉니다.
- Windows 코드 서명과 macOS 공증은 아직 없어서 설치할 때 경고가 뜹니다.
- Microsoft Store 제출용 `POSCHAT-Store-Setup.exe`의 패키지 URL은 공개 HTTPS 주소여야 하므로, 저장소가 비공개이면 GitHub 릴리스 주소를 쓸 수 없습니다([microsoft-store.md](../microsoft-store.md)).
