## 새 기능 (모두 기본 꺼짐, '연결·도구'에서 켬)
- **커넥터**: GitHub(저장소·코드 검색·이슈·PR diff·리뷰·커밋·Actions 실패 로그 분석), Google Drive·Docs·Sheets·Slides·Gmail·Calendar(서비스별 로그인·최소 권한·읽기 전용 옵션), Zotero. 상태 표시, 로그인·재인증·연결 해제·권한 확인, 도구별 승인 정책, 호출 기록.
- **연구 워크스페이스**: arXiv·Semantic Scholar·Crossref·OpenAlex 통합 검색(중복 병합), 논문 라이브러리·태그·BibTeX·추천·인용 관계, 작업 폴더 PDF·문서 인덱싱과 쪽·섹션 인용 검색(RAG), 선택적 Qdrant 벡터 검색, paper-compare 스킬.
- **통합 메모리**: 프로젝트·연구·대화 계층과 에이전트 인계(변경 파일·테스트·커밋·다음 단계). 기억은 POSCHAT 안에서만 씁니다.
- **동기화**: Windows·macOS·Android 사이 종단간 암호화 동기화(폴더 또는 Google Drive 앱 전용 폴더).
- **에이전트 자동화**(PC): Python·Jupyter 실행, SSH 원격 실행 — 매번 승인, 제한·기록.
- **사용량·진단**: 모델별 호출·오류율·지연·토큰·크레딧 추정, 도구 성공률, 👍/👎 평가, 규칙 기반 자동 평가, 선택적 Langfuse 내보내기.

## 보안
- 커넥터 토큰은 OS 보안 저장소에. 메일 전송·리뷰 제출·삭제·코드 실행은 자동 허용 설정과 관계없이 매번 승인.
- 외부 데이터는 지시로 따르지 않도록 표시.

## 고친 버그
- 1.6부터 에이전트의 MCP 도구(Word·논문·Notion 등) 호출이 `NameError`로 실패하던 문제.
- "이번 실행 동안 모두 허용"이 앱을 끌 때까지 유지되던 문제.

## 업그레이드
처음 실행할 때 기존 데이터를 `backups/`에 한 번 복사합니다. 자세한 내용: docs/migration-1.10.md

## 외부 인증·환경 검증이 필요한 항목
실제 GitHub·Google·Zotero·Langfuse 계정, Qdrant·임베딩 API, SSH 서버로 연결해 보지는 못했다(가짜 서버로 테스트). 안드로이드에서 Google 로그인(루프백) 흐름은 실기기 확인이 필요하다.
안드로이드 녹음은 에뮬레이터(가상 마이크)에서 시험했고, 실제 휴대폰의 마이크·배터리·발열은 확인하지 못했다.
