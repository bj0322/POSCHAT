# POSCHAT 1.18.1 — 에이전트가 인터넷에서 직접 조사, /usage, 작업 탭 회색 띠 없앰

에이전트에게 "논문 전수조사"처럼 밖의 자료가 필요한 일을 맡기면, 더 이상 "인터넷에 접속할 수 없다"고 하지 않고 스스로 찾아 읽고 정리합니다.

## 에이전트의 인터넷 도구
- 채팅의 에이전트 모드와 코드의 **작업** 탭(Code 에이전트)에 도구 네 가지가 생겼습니다(`web_research.py`).
  - `web_search`: 웹 검색. 설정에 Firecrawl 키가 있으면 Firecrawl, 없으면 DuckDuckGo, 그것도 안 되면 위키백과.
  - `web_fetch`: 웹페이지·PDF 주소의 글 읽기. 찾을 낱말(query)이 있으면 그 둘레만, 긴 글은 offset으로 이어 읽기. 페이지의 링크도 함께 보입니다.
  - `paper_search`: 주제로 arXiv·Semantic Scholar·Crossref·OpenAlex 검색, **저자 이름**(+소속)을 주면 그 저자의 논문을 최신순으로 모두(최대 200편, OpenAlex → 안 되면 Semantic Scholar). 같은 이름의 다른 저자 후보도 알려 줍니다.
  - `web_download`: PDF 같은 파일을 작업 폴더에 받기(덮어쓰지 않음). Code 에이전트는 수정 자동·전체 자동이면 묻지 않고, 계획 모드에서는 받지 않습니다.
- 에이전트 지시에 "인터넷에 접속할 수 없다고 답하지 말고 직접 찾을 것", 조사·전수조사 진행 방법(계획 → 여러 검색어·출처 → 읽기 → 빠진 것 다시 찾기 → 출처와 함께 정리, 많으면 파일로)과 **오늘 날짜**를 넣었습니다.
- 안전: 검색 결과·읽은 페이지의 링크·사용자가 쓴 주소는 바로 읽고, 에이전트가 만들어 낸 주소는 주소 전체를 보여 주고 묻습니다(웹페이지의 지시로 주소에 정보를 실어 보내는 일을 막음). 이 PC·내부망 주소(리디렉션·DNS 포함)는 읽지 않습니다. 읽은 글은 '외부 데이터'로 감싸 그 안의 지시를 따르지 않습니다. 앱 권한(js_api·파일·실행·API 키)은 웹 내용에 주지 않습니다.
- 끄기: **연결·도구 → 기능 → 에이전트의 인터넷 도구**. AI 실행 정책이 Local Only이고 외부 도구를 막으면 쓰지 않습니다.

## /usage
- 채팅 입력창과 코드 작업 탭에서 `/usage`: 이 앱이 보낸 AI 호출 수·토큰(오늘·이번 달·최근 30일)과 POSTECH GenAI 크레딧을 봅니다. 작업 탭에서는 이 작업의 지시·단계 수도 보입니다.

## 코드 작업 탭
- 입력 줄 아래에 보이던 회색 상자(빈 상태 줄과 탭 바탕)를 없앴습니다. 터미널이 칸 끝까지 채웁니다. 상태 줄은 파일 탭에서만 보입니다.

## 알려진 한계
- 키 없는 검색·논문 API(DuckDuckGo·OpenAlex·Semantic Scholar)는 요청이 몰리면 잠시 거절합니다. 자주 쓰면 Firecrawl 키(설정), `SEMANTIC_SCHOLAR_API_KEY`·`OPENALEX_API_KEY` 환경 변수를 넣으세요.
- 로그인이 필요한 사이트(IEEE Xplore 전문 등)는 읽지 못합니다. 옆 브라우저에서 사용자가 로그인한 뒤 브라우저 에이전트로 다루세요.
- 회색 상자 수정은 Chromium 화면 시험으로 확인했습니다. 실제 WebView2·WKWebView에서 손으로 확인해야 합니다.
