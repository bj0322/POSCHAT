# POSCHAT 1.18.5 — PLMS 개선

## 바뀐 점

- **이번 학기 수업만 먼저**: 수업 목록이 지난 학기와 섞여 나오던 것을 고쳤다. Moodle의 수업 시작·종료일로 이번 학기·예정·지난 학기를 나눠, 이번 학기 수업을 먼저 보이고 지난 학기는 접힌 묶음에 둔다. 에이전트도 사용자가 학기를 따로 말하지 않으면 이번 학기 수업만 다룬다.
- **저장된 계정으로 자동 입력**: 설정의 **PLMS 계정**에 아이디·비밀번호를 저장하면 **SSO 로그인**을 누를 때 로그인 창을 자동으로 채운다. 비밀번호는 OS 보안 저장소(자격 증명 관리자·키체인)에만 저장하고 모델·대화 기록·동기화·화면 상태로 보내지 않는다. `postech.ac.kr` 로그인 창에만, 로그인 한 번에 한 번만 보내고 StonePASS 같은 2단계 인증은 계속 직접 한다.
- **수업 화면 개선**: 한 덩어리 글 대신 공지·게시판·자료·과제 칩으로 거르고 주차·주제별로 묶어 보여 준다. 자료 화면에는 돌아가기 경로와 읽은 분량이 있다. 목록 사이에 `null`이 글자로 나오던 문제를 고쳤다.
- 에이전트의 수업·자료 목록에 `status`·`term`·`kind`·`section`이 추가됐다.

## 한계

- 실제 POSTECH 계정의 SSO·StonePASS 인증과 로그인 후 수업 화면은 아직 손으로 확인하지 못했다. 자동 입력은 학교 로그인 화면의 입력 칸·버튼 구조를 일반적인 형태로 가정한다. 채워지지 않으면 직접 입력하면 되고, 그런 경우 알려 주면 맞춘다.
- 수업 시작·종료일이 없는 수업은 학기를 알 수 없어 이번 학기 쪽에 둔다. 종료일이 없고 시작 후 200일이 지난 수업은 지난 학기로 본다.
- 저장 위치가 OS 보안 저장소를 쓸 수 없는 환경이면 앱 전용 폴더의 파일(소유자만 읽기)에 저장한다.
