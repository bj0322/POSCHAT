# POSCHAT 1.18.0 — GPT, 코드 화면 터미널, SSH 서버의 폴더

본인 OpenAI API 키로 **GPT**를 쓰고, 코드 화면 아래 패널이 **진짜 터미널**이 되었고, 코드 화면에서 **SSH 서버의 폴더**를 열어 일할 수 있습니다.
자세히: [코드 사용법](../code-editor-guide.md#ssh-서버의-폴더에서-일하기-118) · [구조](../architecture/poschat-code.md#ssh-원격-작업-폴더-118) · [보안](../code-security.md)

## 일반 AI 모델 (GPT)
- **설정 → API 방식 → 일반 AI 모델 (GPT)**: 본인 OpenAI API 키(`sk-...`, 또는 환경 변수 `OPENAI_API_KEY`)로 모든 모델 호출을 OpenAI Responses API로 보냅니다(`store: false`).
- 모델: GPT-5.1(권장)·GPT-5.2·GPT-5 mini·GPT-4.1 mini. **모델 목록 불러오기**로 그 키로 쓸 수 있는 대화 모델을 받아 옵니다. 스트리밍·이미지 첨부가 됩니다.
- 요금은 그 키의 OpenAI 계정으로 청구됩니다. POSTECH 키와 모델 설정은 그대로 남습니다(크레딧 확인·음성 보정).

## 코드 화면 아래 패널 = 터미널
- 1.17까지의 '실행' 패널 대신 진짜 대화형 셸입니다: Windows는 PowerShell(ConPTY), macOS·Linux는 로그인 셸. vim·ssh·python 대화형도 됩니다.
- **+** 로 6개까지, **Ctrl+`** 로 열고 접기, 글을 골라 Ctrl+C 복사·Ctrl+V 붙여 넣기, **AI에게 묻기**로 출력(비밀은 가림)을 채팅에 첨부.
- Git·변경 검토는 왼쪽 패널의 탭(파일 · Git · 변경 검토)으로 옮겼습니다.
- 직접 치는 셸이라 승인 창이 없습니다. 이름에 key·token·secret이 든 환경 변수는 넘기지 않습니다.

## SSH 서버의 폴더에서 일하기
- 코드 화면 위 **SSH** → `user@server.postech.ac.kr`(또는 `~/.ssh/config`의 Host) → **연결** → 폴더 고르기 → **이 폴더 열기**.
  파일 트리·편집·찾기·Git·터미널·Code 에이전트(작업 탭)가 모두 그 서버에서 돕니다(VS Code Remote-SSH처럼). 채팅·Lab의 작업 폴더는 그대로 로컬입니다.
- 처음 연결하는 서버는 지문(SHA256)을 확인하고 받아들여야 연결합니다. 지문이 바뀐 서버에는 연결하지 않습니다.
- 인증: SSH 에이전트 → 키(암호문 물음) → OTP 같은 서버 질문 → 암호. 2단계 인증과 `ProxyJump`(게이트웨이) 지원. 암호·OTP는 저장하지 않습니다.
- 서버에는 python3만 있으면 됩니다. 아무것도 설치하지 않고, 작은 도우미를 메모리에서만 돌립니다. 연결이 끊기면 **다시 연결**이 보입니다.

## 알려진 한계
- 터미널·SSH는 Chromium 화면 시험, 시험용 SSH 서버, CI 설치본 진단으로 확인했습니다. 실제 Windows·macOS 앱에서 한글 입력·붙여 넣기·vim과 실제 학교 서버 연결은 손으로 확인해야 합니다.
- SSH: 서버는 Linux·macOS만, 격리 작업(git worktree)은 로컬 작업 폴더에서만, `~/.ssh/config`의 Include는 읽지 않습니다. 원격 도우미는 Python 3.8~3.13에서 시험했습니다(3.6·3.7은 문법 검사만).
- 안드로이드 앱에는 터미널·SSH가 없습니다(PC 앱에서 쓰세요).
