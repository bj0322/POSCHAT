# POSCHAT 1.18.6 — PLMS 백그라운드 접근

## 바뀐 점

- **브라우저 없이 PLMS**: 설정에 PLMS 계정을 저장하면 화면에 붙이지 않은 웹 뷰에서 SSO 로그인하고 수업·공지·자료를 조회한다. 사이드바 **PLMS → 로그인**이나 **내 수업 불러오기**를 눌러도 오른쪽에 브라우저가 열리지 않는다.
- **채팅에서 바로 PLMS**: 에이전트 모드의 채팅이 브라우저를 열어 두지 않아도 PLMS 도구(수업 목록·수업 내용·공지·자료 읽기)를 쓴다. 이전에는 브라우저가 닫혀 있으면 PLMS 도구 없이 일반 대화로 처리해 "로그인이 필요해 접근할 수 없다"고 답했다. 세션이 없거나 만료되면 저장된 계정으로 알아서 다시 로그인하고 같은 조회를 이어 간다.
- **추가 인증만 사람이**: StonePASS 같은 추가 인증이 필요하면 그때만 브라우저를 보여 주고 알린다. 인증을 마치면 다시 숨긴다.
- **계정 잠김 방지**: 학교가 로그인을 거부하거나 사용자 인증이 끝나지 않으면 10분 동안 자동 로그인을 다시 시도하지 않는다. 사이드바에서 직접 누른 로그인은 막지 않는다.
- 계정을 저장하면 PLMS 연결도 함께 켠다.

## 한계

- 숨은 웹 뷰의 로그인·조회는 CI의 Windows·macOS 실제 창 시험으로 동작을 확인하지만, 실제 POSTECH 계정의 SSO·StonePASS 왕복은 아직 손으로 확인하지 못했다. 실제 로그인 화면의 입력 칸·버튼 구조는 이 서버의 헤드리스 브라우저로 확인했다(SSO 버튼 → SSO 화면 → 입력·제출).
- 로그인 실패 이유는 화면 글로 짐작한다(계정 거부·추가 인증·알 수 없음). 알 수 없는 경우 추가 인증으로 보고 브라우저를 보여 준다.
- 과제 제출·출석·성적 변경은 여전히 제공하지 않는다.
