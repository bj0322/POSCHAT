# POSCHAT 1.13.0 — 브라우저

## 브라우저 (새 기능)
- 왼쪽 사이드바의 **브라우저**를 누르면 앱 창이 둘로 나뉘어, 왼쪽에는 채팅, 오른쪽에는 웹페이지가 보입니다. 가운데 막대를 끌어 너비를 바꿉니다(다음에 열 때도 그 너비).
- 채팅 위의 브라우저 막대: 뒤로·앞으로·새로 고침, 주소 또는 검색어 입력, 기본 브라우저로 열기, 닫기.
- **이 페이지에 대해 묻기**: 지금 보는 페이지의 글을 채팅에 첨부하고 질문 초안을 넣습니다. **선택한 부분 묻기**: 드래그한 부분만 첨부합니다.
- **연구 라이브러리에 저장**: arXiv·DOI 논문 페이지를 한 번에 연구 라이브러리에 더합니다.
- **에이전트**: 브라우저가 열려 있으면 에이전트가 지금 페이지를 읽고(`browser_read`), 주소를 열 수 있습니다(`browser_open`, 여는 주소를 보여 주고 매번 승인).
- 안드로이드: 세로 화면은 위(웹페이지)·아래(앱), 가로 화면은 왼쪽(앱)·오른쪽(웹페이지)으로 나눕니다. 뒤로 가기는 웹페이지부터 뒤로 갑니다.

## 구현과 격리
- 웹페이지는 플랫폼의 네이티브 웹 뷰가 그립니다: Windows는 앱 창에 WebView2를 하나 더 붙이고, macOS는 앱 창을 NSSplitView로 나눠 WKWebView를 하나 더 두고, 안드로이드는 WebView를 하나 더 둡니다. 붙이지 못하면 앱 창 옆에 붙는 창으로 엽니다.
- 웹페이지 쪽 뷰에는 POSCHAT의 Python API(파일 수정·Python 실행·MCP·API 키)에 닿는 통로를 하나도 주지 않습니다(js_api·host object·WebMessage·스크립트 메시지 핸들러·JavascriptInterface 없음). 앱이 페이지를 읽기만 합니다.
- 읽은 페이지는 AI에게 '외부 데이터'로 표시되어, 페이지 안의 지시("이전 지시를 무시하고…")를 따르지 않습니다.
- http·https만 엽니다(file:, javascript:, data:, 앱 내부 주소, 링크 로컬 주소는 막음). 새 창은 같은 뷰에서 열고, 다운로드와 카메라·마이크·위치 권한 요청은 거절합니다. 쿠키·저장소는 앱 화면과 다른 프로필 폴더(`browser-profile`)에 둡니다.
- CI가 실제 Windows·macOS 창에서 웹페이지 뷰를 붙여 열기·이벤트·글과 선택 읽기·논문 식별자·격리·뒤로 가기·닫기를 확인합니다(`tests/browser_spike.py`).
