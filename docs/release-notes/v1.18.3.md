# POSCHAT 1.18.3 — 업데이트 서버를 HTTPS 도메인으로

새 버전 확인과 설치 파일 받기가 `https://pidstech.com`을 씁니다. 1.18.2는 임시 주소(`http://3.38.118.65`)를 썼습니다.

## 바뀐 점
- `updates.UPDATE_BASE_URL`이 `https://pidstech.com`입니다. 연결이 암호화되어 업데이트 확인 요청을 도청할 수 없고, 설치 파일의 Ed25519 서명·SHA-256 확인은 그대로입니다.
- 서버는 1.18.2 앱을 위해 옛 주소(`http://3.38.118.65`)도 계속 서비스합니다. 서버가 피드를 주소별로 따로 만들어 두 세대가 모두 업데이트됩니다([운영 안내](../update-server.md)).
- 홈페이지(`https://pidstech.com`)의 다운로드 버튼이 서버의 최신 설치 파일을 바로 가리킵니다.

## 업데이트 경로
- 1.18.1 이하(GitHub 확인) → 1.18.3: 저장소가 공개인 동안 GitHub에서 바로 받습니다.
- 1.18.2(옛 주소) → 1.18.3: 서버의 옛 주소 피드로 받습니다.

## 알려진 한계
- Windows 코드 서명과 macOS 공증은 아직 없어서 설치할 때 경고가 뜹니다.
- Microsoft Store 제출용 `POSCHAT-Store-Setup.exe`는 서버에 올라가지 않습니다([microsoft-store.md](../microsoft-store.md)).
