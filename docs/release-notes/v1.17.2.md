# POSCHAT 1.17.2 — Code 에이전트를 터미널처럼, 코드는 전체 화면으로

Code 에이전트의 **작업** 탭이 Claude Code 같은 터미널이 되었고, **코드**는 채팅 옆에 나누어 띄우지 않고 하나의 전체 화면으로 열립니다.
자세히: [사용법](../code-editor-guide.md#code-에이전트-3-터미널처럼-쓰기-1172) · [구조](../architecture/poschat-code.md#code-에이전트-3-1172--터미널처럼)

## 코드는 하나의 전체 화면
- 왼쪽 위 **코드**를 누르면 채팅 자리 전체에 코드 화면이 열립니다(가운데 나누는 막대·크게 보기 단추는 없앴습니다).
- 사이드바에서 대화·새 채팅·PO노트·Lab·라이브러리를 누르거나 오른쪽 위 ×를 누르면 채팅(그 화면)으로 돌아갑니다. 열린 탭·저장하지 않은 내용은 그대로 남아, 다시 **코드**를 누르면 이어집니다.
- 선택한 코드를 **AI에게 묻기**로 보내면 채팅으로 돌아가 묻습니다.

## 작업 탭이 터미널처럼
- 맨 아래 `>` 줄에 쓰고 **Enter**. 진행은 위로 쌓입니다: `● Read(calc.py) ⎿ 2줄 읽음`, `● Update(calc.py)`와 줄 번호가 붙은 diff, `● Bash(명령)`과 실시간 출력, `● Update Todos`.
  긴 출력은 접히고 **Ctrl+O**로 펼칩니다. 입력 줄 위에 `✻ 생각하는 중… (8초 · esc로 멈춤)`, 지시가 끝나면 걸린 시간·바뀐 파일 수가 보입니다.
- **승인은 기록 안에서**: 1 예 · 2 이 명령은 다시 묻지 않기(수정이면 '이 작업 동안 수정은 묻지 않기') · 3/Esc 아니요, 다르게 하라고 알려 주기(쓴 글이 추가 지시로 감). 숫자·↑↓·Enter로 고릅니다.
  계획 모드가 끝나면 '이 계획으로 진행할까요?'도 같은 방식입니다. 작업 탭이 안 보일 때 온 승인은 예전처럼 창으로 묻습니다.
- **단축키**: Shift+Tab 권한 모드(작업 중에도 다음 단계부터 반영) · Esc 멈춤 · Esc 두 번 마지막 지시 되돌리기 · ↑↓ 지난 입력 · Tab 자동 완성 · Ctrl+L 화면 비우기 · Ctrl+C 입력 지우기 · `?` 단축키 · Shift+Enter 줄 바꿈.
- **입력 앞글자**: `!명령`(작업 폴더에서 바로 실행, 출력은 다음 지시의 맥락으로. 위험·인터넷 명령은 한 번 더 물음) · `#메모`(AGENTS.md에 한 줄) · `@파일`(파일·폴더를 지시에 붙이기, 자동 완성) · `/명령`(자동 완성).
- **명령**: 위쪽 메뉴·옆 패널 대신 `/clear` `/resume` `/status` `/diff` `/revert` `/todos` `/mode` `/plan` `/permissions` `/memory` `/worktree` `/apply` `/keep` `/discard` `/delete`.
- **프로젝트 명령**: 작업 폴더의 `.poschat/commands/이름.md`(또는 `.claude/commands/`)가 `/이름` 명령이 됩니다(`$ARGUMENTS`에 인자).

## 알려진 한계
- Chromium 화면 시험과 CI로만 확인했습니다. 실제 WebView2·WKWebView에서 Shift+Tab·Esc·Ctrl+O·Ctrl+L이 창 단축키와 겹치지 않는지, 한글 조합 중 Enter·↑↓, macOS의 Ctrl·Cmd 차이는 손으로 확인해야 합니다.
- 작업 폴더는 보안 격리가 아닙니다. `!` 명령은 직접 친 명령이라 묻지 않고 실행합니다(위험·인터넷 명령만 다시 물음).
