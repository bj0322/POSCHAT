# POSCHAT 1.18.4 — PLMS와 에이전트 연결

## 새 기능

- **PLMS 로그인·참여 수업·공지·강의자료 읽기**: 내장 브라우저에서 SSO·StonePASS를 직접 인증한 뒤 수업과 공지·자료를 조회한다. PDF·Office·한글·텍스트 자료를 20MB까지 읽고 긴 자료를 이어 읽는다.
- **PLMS 에이전트 도구**: 참여 수업 목록, 수업 내용, 게시판·자료 본문을 조회해 정리한다. PLMS 조회는 작업 폴더 없이도 가능하다. 비밀번호·OTP·쿠키를 모델에 보내지 않는다. [사용법·검증 범위](../plms-guide.md)
- **여러 세션 동시 실행**: 채팅·Code 작업을 동시에 실행하고 각 세션을 따로 멈추거나 추가 지시한다. Code 새 세션 선택을 늦게 도착한 응답이 덮어쓰는 문제를 수정했다.
- **ponytail·graphify 내장 스킬**: 최소 구현 지침과 코드 관계 그래프 탐색. Graphify 실행 환경은 별도로 필요하다.
- **데스크톱 전용 빌드**: 앞으로 Windows·macOS만 빌드한다. Android 소스는 보관하며 APK를 배포하지 않는다.

## 한계

- 실제 POSTECH 계정의 SSO·StonePASS 인증과 로그인 후 수업별 화면은 아직 손 시험하지 않았다. 자동 시험은 로그인·수업·공지·자료의 가짜 응답과 화면 흐름, 네이티브 쿠키 API를 검증한다.
- PLMS의 외부 사이트·동영상·특수 모듈, 자동 제출·출석·성적 변경은 지원하지 않는다. 읽기 요청이 학교 서버의 열람 기록에 남을 수 있다.
- 에이전트가 읽은 자료는 선택한 AI 서비스와 대화 기록에 포함될 수 있다. 연결 해제는 기존 기록과 학교 공통 SSO 세션을 지우지 않는다.
- 공유 브라우저는 에이전트 한 세션이 사용한다. 병렬 코드 작업에서 같은 파일을 고칠 때는 worktree로 분리한다.
- Windows 코드 서명·macOS 공증 여부는 기존 배포 설정을 따른다.
