# POSCHAT 1.17.1 — Code 에이전트가 Claude Code·Codex처럼

코드 화면의 **작업** 탭(Code 에이전트)이 Claude Code·Codex처럼 일합니다. 자세히: [사용법](../code-editor-guide.md#code-에이전트-2-claude-codecodex처럼-1171) ·
[구조](../architecture/poschat-code.md#code-에이전트-2-1171--claude-codecodex처럼)

## 권한 모드
- **계획 모드**: 파일을 고치거나 명령을 실행하지 않고 코드를 읽어 계획을 제안합니다. **이 계획으로 진행**을 누르면 그 계획대로 고치기 시작합니다.
- **매번 묻기** · **수정 자동**(기본) · **전체 자동**(명령도 바로 실행하되 위험한 동작·인터넷을 쓰는 명령은 물음).
- 명령 승인 창의 **다시 묻지 않기**: 이 작업 폴더에서 같은 명령은 묻지 않습니다. 이어 붙인 명령(`&&`·`|`)·위험한 동작·인터넷을 쓰는 명령은 그래도 묻습니다.

## 일하는 방식
- **추가 지시**: 에이전트가 일하는 중에도 지시를 보내면 다음 단계부터 반영합니다.
- **슬래시 명령**: `/init`(AGENTS.md 만들기), `/review`(Git 변경 코드 리뷰), `/test`(테스트 실행·고치기), `/plan`, `/undo`, `/compact`, `/new`, `/mode`, `/help`.
- **마지막 지시 되돌리기**: 지시마다 고치기 전 상태를 남겨, 마지막 지시로 바뀐 파일만 되돌립니다(작업 전체 되돌리기도 그대로).
- **프로젝트 지침**: AGENTS.md·CLAUDE.md를 읽고 따르며, 테스트·빌드·린트 명령(package.json·pyproject·Makefile 등)과 Git 상태를 에이전트에게 알려 줍니다.
- **격리 작업 공간(git worktree)**: 새 작업을 따로 만든 브랜치·작업 공간에서 하고, 끝나면 원래 폴더에 **적용**하거나, **브랜치로 남기거나**(커밋해 두고 Git으로 합치기),
  **버립니다**. 적용은 '다 되거나 그대로'입니다(겹치면 원래 폴더를 바꾸지 않음).
- **새 도구**: 줄 번호 읽기(나눠 읽기), 파일 찾기(glob), 여러 곳 한 번에 고치기(multi_edit, 하나라도 안 맞으면 그대로), 같은 글 모두 바꾸기,
  백그라운드 명령(개발 서버 등, 작업이 끝나면 멈춤), 단계마다 한 줄 설명.

## 그 밖에
- 손익분기 실험 도구 `tools/breakeven_experiment.py`: 같은 요청을 프런티어 직접·경량 혼자·경량+상담으로 실제 모델에 보내 토큰·품질을 재고 결정 함수를 비교합니다
  (API 키가 있어야 실행, [평가 문서](../adaptive-ai-evaluation.md#손익분기-실험-toolsbreakeven_experimentpy-117-뒤)).
- 명령 실행 기록의 최근 출력이 실행하는 동안에도 갱신됩니다.

## 알려진 한계
- 실제 Windows·macOS 앱에서 격리 작업 공간·백그라운드 명령을 손으로 확인하지 않았습니다(자동 시험과 CI 창 시험만).
- 격리 작업 공간에는 Git에 없는 파일(설치한 의존성 등)이 없습니다. 테스트에 필요하면 그 공간에서 설치해야 합니다.
- 작업 폴더는 보안 격리가 아닙니다. 전체 자동은 명령을 묻지 않으므로 믿는 저장소에서만 쓰세요.
