# AI 실행 정책·로컬 AI 설정 (1.17)

**설정 → AI 실행 정책 → 열기**에서 켭니다. 기본은 꺼짐이고, 켜기 전에는 예전처럼 대화마다 고른 Cloud 모델만 씁니다.

## 1. 로컬 AI(Ollama) 설치 — 선택
1. [ollama.com/download](https://ollama.com/download)에서 Windows·macOS용 Ollama를 설치하고 실행합니다. POSCHAT은 Ollama나 모델을 함께 설치하지 않습니다.
2. 정책 창의 **로컬 AI** 칸이 `연결됨 · Ollama <버전> · http://127.0.0.1:11434 (이 PC)`로 바뀌는지 봅니다.
3. **모델 받기**에 이름(예: `qwen2.5:7b`, `gemma3:4b`, `llama3.2:3b`)을 넣고 **크기·라이선스 확인**을 누르면 Ollama 공개 저장소에서 크기·출처·라이선스와
   남은 디스크를 먼저 보여 줍니다. 읽어 보고 **받기**를 누릅니다(진행률·멈춤). 터미널의 `ollama pull <모델>`로 받아도 됩니다.
4. 표의 **기능·라이선스**로 이미지·도구 호출·문맥 길이를, **속도 측정**으로 토큰/초를, **시험 대화**로 답을 확인하고 **기본 로컬 모델**을 고릅니다.
   메모리 칸은 모델 파일 크기와 문맥 길이로 어림한 값이며, 이 PC가 모자랄 수 있으면 라우터가 그 모델을 쓰지 않습니다.
5. 다른 PC(예: 연구실 GPU 서버)의 Ollama를 쓰려면 주소를 바꾸고 **다른 PC의 Ollama 허용(원격)**을 켭니다. 사설망은 http, 인터넷은 https만 됩니다.

모델마다 라이선스가 다릅니다(상업적 이용·재배포 제한이 있을 수 있음). 받기 전에 꼭 읽으세요.

## 2. 정책
| 정책 | 동작 |
|---|---|
| Economy(절약) | 가벼운 일(요약·번역·분류·추출·일상 대화)은 로컬 먼저. 검증에 실패하면 허용한 범위에서 위 단계로 |
| Balanced(균형, 권장) | 종류·난이도로 고름. 연구 추론·코드 수정·에이전트 작업은 Cloud 먼저 |
| Quality(품질) | Cloud 먼저. 로컬은 측정해서 성공률 95% 이상이 확인된 가벼운 일만 |
| Local Only(로컬 전용) | Cloud 모델을 전혀 부르지 않음(라우팅·검증·요약·PO노트 노트·대화 요약·음성 보정까지). 로컬 모델이 없거나 못 하는 일이면 오류로 알림 |

## 3. 경량 Cloud 모델(3단계) — 선택, 기본 꺼짐
**Cloud와 승격 → 3단계 켜기**를 켜고 **경량 Cloud 모델**에서 Claude Haiku 5.5(개인 Claude API)나 GPT-5 mini·Gemini Flash(POSTECH)처럼
싸고 빠른 모델을 고르면 **사용자 → 경량 모델 → 프런티어**의 3단계가 됩니다. '3단계 켜기'를 끄면 경량 모델을 골라 두어도 쓰지 않습니다(로컬 → 프런티어 2단계).
- 보통 일은 경량 모델이 혼자 답합니다. 검증에 실패하면 프런티어가 다시 답합니다.
- 어려운 일은(Economy·Balanced에서 **상담**을 켰을 때) 경량 모델이 대화를 이끌며 확신이 없는 부분만 프런티어에 짧은 질문으로 묻고,
  그 답을 받아 최종 답을 씁니다. 프런티어는 대화 전체 대신 질문과 발췌만 받습니다. 상담 기록은 대화마다 남아 다음 상담에 이어 붙습니다.
- 파일·명령·외부 작업으로 이어지는 에이전트 단계는 언제나 프런티어가 맡습니다.
- 상담하면 경량 모델을 한 번 더 부르므로 조금 느립니다. 비용이 줄어드는 정도는 두 모델의 가격 차이에 달려 있습니다(아래 손익분기).

### 단가와 손익분기
**단가** 표에 경량·프런티어 모델의 100만 토큰당 입력·출력 단가(선택: 캐시 읽기·캐시 쓰기·호출당 고정 비용)를 넣습니다. 두 모델의 단위만 같으면 됩니다
(USD, POSTECH 크레딧 등). 앱은 모델 가격을 지어내지 않습니다. 비워 두면 앱 안내에 크레딧 근거가 있는 모델(Claude Sonnet·Opus 5.5)만 크레딧으로 계산합니다.
- **단가 비율 r** = 경량 단가 ÷ 프런티어 단가(이번 요청 꼴의 호출 비용 비율). **손익분기 r\***는 경량 방식의 기대 비용이 프런티어 직접과 같아지는 r입니다.
  r < r\*일 때만 경량 모델(혼자·상담)이 쌉니다.
- r\*는 요청마다 다시 계산합니다: 요청 길이, 상담 질문·프런티어 답·최종 답의 길이(서버가 알려 준 실측 평균, 없으면 어림), 경량 답이 검증에 실패해 승격될 확률
  (그 작업의 측정 기록 10개 이상이면 실측, 아니면 15%), 캐시 여부와 캐시 단가.
- 단가를 넣으면 규칙이 경량 모델을 골랐어도 **프런티어 직접이 더 싼 요청은 프런티어로** 보냅니다(이유: '단가 비율 0.9 ≥ 손익분기 0.24 → 프런티어가 더 쌈').
  반대로 규칙이 품질 때문에 프런티어로 정한 요청은 싸더라도 경량으로 내리지 않습니다.
- 예(입력·출력 단가가 같은 비율, 캐시 없음, 최종 답 600·상담 답 500토큰 어림): 상담의 r\*는 요청 2천 토큰에서 약 0.24, 8천에서 0.39, 3만2천에서 0.47입니다.
  짧은 요청은 프런티어의 상담 답이 최종 답만큼 길어 상담이 거의 이득이 없고, 긴 대화일수록 프런티어가 대화 전체를 읽지 않아 이득이 커집니다.
  경량 모델이 대화를 두 번 읽으므로 캐시가 없으면 r\*는 1/2을 넘지 못합니다. 창의 **손익분기 계산**으로 지금 단가의 값을 볼 수 있습니다.

### 프롬프트 캐싱 — 기본 켜짐(1.18.8)
**프롬프트 캐싱**을 켜면 호출마다 같은 앞부분을 서버 캐시 대상으로 표시합니다(Claude API의 `cache_control`). 상담 뒤 경량 모델의 두 번째 호출(대화 전체가 같음)과
에이전트 단계(지시·도구·대화가 같음)에서 입력 비용을 줄입니다. 캐시 쓰기는 일반 입력보다 비쌀 수 있고, 모델별 최소 길이보다 짧은 글은 캐시되지 않습니다.
여러 단계를 도는 에이전트 작업과 상담에서만 쓰고, 한 번에 끝나는 대화에는 표시하지 않습니다. 끄려면 정책 창에서 해제합니다.
OpenAI 호환 서버(POSTECH GenAI)는 표시 방법이 없어 그대로 보냅니다(서버가 스스로 캐시하면 사용량에 '캐시 읽기'로 보입니다).

### 개발자 모드
**설정 → 개발자 모드**를 켜면 답변 아래 모델 표시를 펼쳤을 때 호출마다 서버가 알려 준 실제 토큰(입력·출력·캐시 읽기·캐시 쓰기), 손익분기 계산(r, r\*, 방식별 기대 비용,
승격 확률), 이유 코드, 원본 JSON이 보입니다. **연결·도구 → 사용량·진단**에는 단계별 실측 토큰 합계·캐시 적중률, 요청 길이별 손익분기 표, 최근 라우팅·호출·검증 기록,
JSON 복사가 생깁니다. 기록에는 질문·답·첨부 내용이 없습니다.

## 4. 그 밖의 설정
- **승격**: 로컬·경량 답이 검증을 통과하지 못하면 위 단계로 다시 답하기(요청당 최대 0~2번). 형식 문제면 같은 로컬 모델로 한 번 더.
- **비용**: 주간 Cloud 호출 수·주간 크레딧·요청당 크레딧 한도(0이면 없음). 크레딧은 근거 있는 모델만 추정합니다.
- **응답 속도**: '빠른 응답 우선'이면 속도를 잰 로컬 모델(15토큰/초 이상)로 쉬운 일을 더 보냅니다.
- **개인정보**: 민감 정보(키·주민번호·카드·연락처)가 보이는 요청은 로컬에서만, 첨부를 Cloud로 보내지 않기, Local Only일 때 외부 도구(MCP) 막기.

## 5. 쓰기
- 대화 위 모델 목록: **자동 (AI 실행 정책)**, **로컬 · 모델 이름**, Cloud 모델. 자동만 정책대로 고르고, 나머지는 고른 모델만 씁니다.
- 답변 아래 표시(예: `Local · 요약`, `Light ⇄ Frontier · 연구 추론`, `Local → Cloud · 요약`)를 누르면 모델·이유·시간·Cloud 호출·비용 추정·검증·승격·상담이 보입니다.
- 통계: **연결·도구 → 사용량·진단 → Adaptive AI**.

## 6. 실제 점검(사용자 PC)
```
python tools/local_ai_check.py --model qwen2.5:7b                 # 로컬 1~8단계
python tools/local_ai_check.py --model qwen2.5:7b --cloud --yes   # Cloud 승격·비용 기록까지(Cloud 호출 2번 이하)
```
실행하지 않은 단계는 `SKIP`으로 나옵니다.

## 7. 플랫폼
안드로이드에서는 로컬 AI를 쓸 수 없습니다. 자동 선택·경량 모델·Local Only 차단은 그대로 됩니다(Local Only에서는 로컬 모델이 없어 오류로 알립니다).
