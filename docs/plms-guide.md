# PLMS 로그인·수업·공지·자료 읽기 (1.18.4)

1. 사이드바 **PLMS → SSO 로그인**을 누른다. 오른쪽 내장 브라우저에서 학교 계정으로 로그인하고 필요한 StonePASS 인증을 직접 마친다. 기본 브라우저에서 로그인한 상태는 자동으로 공유되지 않는다.
2. **PLMS → 내 수업 불러오기**를 누른다. 참여 수업을 선택하면 수업 내용과 공지·자료 링크가 나온다.
3. 공지 게시판 → 게시글 → 첨부 파일 순서로 누르거나, 강의자료를 선택한다. PDF, docx, pptx, xlsx, xlsm, hwp, hwpx, txt, md, csv를 20MB까지 읽는다. 긴 자료는 **이어서 읽기**를 누른다. 스캔 PDF의 OCR은 지원하지 않는다.
4. **에이전트에게 수업 정리 맡기기** 또는 **이 자료 묻기**를 누른다. 질문을 확인하고 보내면 에이전트가 필요한 자료를 조회한다. 에이전트 모드를 켜고 브라우저를 열어 둔다. PLMS만 조회할 때는 작업 폴더가 없어도 된다.
5. 로그인 만료·권한 오류가 나면 다시 로그인한다. **연결 해제**는 조회 기능을 끄고 PLMS 도메인 전용 쿠키를 지운다. POSTECH 공통 SSO 세션까지 로그아웃하는 기능은 아니며 기존 대화 기록도 지우지 않는다.

## 에이전트 도구

- `plms_courses`: 현재 계정의 참여 수업 목록.
- `plms_course(course_id)`: 참여 수업 본문과 지원하는 공지·자료 링크.
- `plms_read(course_id, url, parent=[], query="", offset=0)`: 발견한 링크의 본문·파일 읽기. 게시판·폴더·게시글을 거쳤다면 `parent`에 수업에서부터 거친 상위 링크를 순서대로 지정한다(최대 4단계). 반환된 `next_offset`으로 이어 읽는다.

에이전트 목록은 12개씩 반환하며 `next_item_offset`을 같은 도구의 `item_offset`에 넣어 나머지 목록을 확인한다.

수업별로 학교가 허용한 읽기 권한을 그대로 사용한다. 주소를 임의로 만들어 다른 수업 자료를 가져오는 방식은 지원하지 않는다. 수업 목록은 내 강좌 페이지와, 지원하는 경우 Moodle의 수강 목록 조회 AJAX 함수로 확인한다. 별도 Moodle API 토큰을 요구하지 않는다.

## 데이터와 한계

- 비밀번호·OTP는 POSTECH 웹페이지에 직접 입력한다. 앱이 저장하거나 모델에 넘기지 않는다. 브라우저 쿠키는 로컬 네이티브 저장소에 있고, 조회할 때만 메모리로 읽는다. 외부 호스트로 리다이렉트되면 인증 쿠키를 보내지 않고 중단한다.
- 에이전트가 읽은 공지·강의자료는 대화 기록에 일부 남고 사용자가 선택한 AI 서비스에 전송될 수 있다. 자료는 외부 데이터로 표시한다. 개발자 업데이트 서버로 전송하지 않는다.
- 다운로드 파일은 텍스트 추출용 임시 폴더에서 읽은 뒤 지운다. 상시 동기화·자료 영구 보관·일괄 다운로드는 하지 않는다.
- Windows WebView2·macOS WKWebView가 필요하다. 네이티브 뷰가 아닌 대체 브라우저 모드는 PLMS 쿠키 조회를 지원하지 않는다.
- 자동 제출·출석·퀴즈 응시·성적 변경은 제공하지 않는다. 자료 조회 자체가 PLMS 서버의 ‘열람함’ 기록에 남을 수 있다.
- 학교 밖 사이트, 동영상, 특수 강의 모듈, 동적 전용 게시판은 읽지 못할 수 있다. 지원하지 않는 링크는 원문 브라우저에서 확인한다. 학교 화면·설정 변경에 따라 파서 보완이 필요할 수 있다.
- 공유 브라우저를 사용하는 에이전트는 한 번에 한 세션이다. 로그인·연결 해제는 브라우저를 쓰는 에이전트를 멈춘 뒤 한다. 연결을 해제해도 이미 질문에 포함된 자료와 대화는 남는다.

## 검증 범위

가짜 로그인 대시보드·수업·중첩 게시판·파일 응답을 이용해 수강 목록, 본문, 문서 추출, 만료, 외부 주소 차단, 크기 제한, 취소, 에이전트·화면 흐름을 시험한다. 네이티브 CI는 두 운영체제의 쿠키 API 호출을 점검한다. **실제 POSTECH 계정으로 SSO·StonePASS 왕복과 로그인 후 수업별 화면을 확인하는 손 시험은 아직 수행하지 않았다.** 학교 계정별 기능 호환을 확인한 것으로 해석하지 않는다.
