# 요약 스킬

## 절차
1. 요약 대상이 파일이면 read로 전체 내용을 먼저 읽는다. 대화에 붙여 넣은 글이면 그대로 쓴다.
2. 글의 목적과 독자를 한 문장으로 파악한다.
3. 아래 형식으로 요약한다.
4. 사용자가 파일로 저장해 달라고 하면 write로 저장한다. 파일에는 요약 내용만 넣는다.

## 출력 형식
- **한 줄 요약**: 전체 내용을 한 문장으로
- **핵심 내용**: 3~7개의 불릿, 각 불릿은 한 문장
- **수치·고유명사**: 원문에 나온 숫자, 날짜, 인명, 기관명은 원문 그대로 옮긴다
- **추가 확인 필요**: 원문만으로 불분명한 점이 있으면 적는다

원문에 없는 내용은 추가하지 않는다.
