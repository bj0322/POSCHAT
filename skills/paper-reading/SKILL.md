# 논문 읽기 스킬

paper MCP 도구로 논문을 나눠 읽고, 처음 보는 사람도 이해하도록 설명한다.

## 절차
1. 논문 찾기: 제목·주제만 있으면 `paper.search`로 찾는다. 학회·저널 논문은 `source: "scholar"`도 써 본다. 후보가 여럿이면 사용자에게 고르게 한다.
2. 개요: `paper.info`로 제목·저자·게재처·인용 수·한 줄 요약(TLDR)·초록을 본다.
3. 본문: `paper.read`를 section·pages 없이 불러 목차와 앞부분(초록·서론)을 읽는다.
4. 핵심 섹션을 차례로 읽는다: 방법(Method/Approach) → 실험·결과(Experiments/Results) → 결론·한계(Conclusion/Limitations). 질문과 상관없는 섹션은 건너뛴다.
5. 배경 지식이 필요하면 `paper.related`(references)로 많이 인용된 선행 논문을 확인한다.
6. 아래 형식으로 설명한다. 사용자가 파일을 원하면 word·notion 도구로 저장한다.

## 설명 형식
- **한 줄 요약**: 이 논문이 무엇을 했는지 한 문장으로
- **왜 중요한가**: 풀려던 문제와 기존 방법의 한계
- **핵심 아이디어**: 비유를 섞어 3~5개 불릿. 수식은 의미를 말로 먼저 풀고 필요하면 LaTeX($...$)로 덧붙인다
- **방법**: 입력 → 처리 → 출력 순서로
- **결과**: 주요 수치는 원문 그대로(데이터셋·지표 이름 포함)
- **한계와 생각해 볼 점**
- **용어 정리**: 처음 나오는 전문 용어를 표로 (용어 | 쉬운 설명)
- **더 읽을거리**: 관련 논문 2~3편 (paper 값 포함)

## 규칙
- 원문에 없는 내용을 지어내지 않는다. 수치·이름은 원문 그대로 옮기고, 추측은 추측이라고 밝힌다.
- 설명은 한국어로 하되 전문 용어는 처음에 원어를 괄호로 함께 쓴다. 예: 주의 메커니즘(attention).
- 사용자의 수준(학부생, 대학원생, 비전공자)을 알면 그에 맞춘다.
- 그림·표는 PDF에서 글자만 읽히므로, 캡션과 본문 설명으로 내용을 추정했다면 그렇게 밝힌다.
